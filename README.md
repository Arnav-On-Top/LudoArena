A Ludo Game Website with backend node.js. A user can make a room code and share with other users that will connect them to the same room. Roll the dice and get a 6 on it to start the game. There are no safe squares and three six rule, to be added in version 2. Moves are updated real time. The server manages the room, the token positions and dice rolls. WebSocket keeps the game updated real time to reduce lags.

Tech Stack: HTML, CSS and JS

Click this link https://ludoarena-dus7.onrender.com to play. you can copy paste the link in to tabs to play as multiple player. Needs atleast 2 players to start the game.
